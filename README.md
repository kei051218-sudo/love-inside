# Love Inside

참여형 감정 게임 — 오늘 밤 당신의 사랑은 어디로 가나요?

## 소개

제주 1주년 커플의 딱새우 논쟁에서 시작된 밤 12시 전화 통화.
5개의 감정 캐릭터(분이, 서럽, 두근, 혼미, 도도)와 함께
당신의 선택이 이 사랑의 결말을 결정합니다.

## 엔딩
- 💛 해피엔딩: 오늘 밤, 우리 괜찮아
- 🖤 결별엔딩: 우리, 여기까지였나봐
- 🌀 미결엔딩: 오늘 밤은, 그냥 이대로

## 기술 스택
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Vercel 배포

## 개발
```bash
npm install
npm run dev
```
